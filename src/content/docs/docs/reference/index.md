:::note
Status: Planned. No reference material is published yet.
:::

Reference material — the REST/OpenAPI definition, CRD and YAML schemas, CLI
command reference, and the extension contract — is intended to be generated
from the actual source once it exists, so it cannot drift from the
implementation. None of it is public yet, and no command, endpoint, or
schema should be assumed to exist based on this placeholder.
