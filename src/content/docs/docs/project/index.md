## Roadmap status

Tritolem distinguishes three states for any capability mentioned in this
documentation:

- **Planned** — described as product direction; no working code exists yet.
- **Implemented** — built and demonstrable, but not yet declared stable.
- **Supported** — implemented and covered by the project's ongoing
  maintenance commitment.

Everything in this documentation is currently **planned**. Nothing is
implemented or supported yet. Pages are updated to the next state only once
that state is actually true.
