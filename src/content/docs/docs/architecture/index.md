:::note
Status: Planned. No detailed architecture is published yet.
:::

Architecture documentation is published only once the underlying design has
gone through Tritolem's architecture decision process and been accepted.
None of that detail is public yet.

Once available, this section is intended to cover the control plane versus
workload split, the pull-based agent design, infrastructure and trust
boundaries, and the service status model — scoped to what has actually been
decided and built, not the full internal design discussion.

See **[Concepts](/docs/concepts/)** for the high-level model that is already
approved for public description.
