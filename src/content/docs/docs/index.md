Tritolem is a Kubernetes-native, modular platform for providers to run
standardized managed services across many existing Kubernetes clusters.
Customers order and manage services through one API and CLI, without
handling Helm, clusters, or operations themselves.

:::note
Tritolem is in early, greenfield development. This documentation describes
the intended product direction, not a released product. No feature is
implemented or supported unless a page explicitly says so.
:::
